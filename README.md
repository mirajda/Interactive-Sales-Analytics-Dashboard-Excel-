# Interactive-Sales-Analytics-Dashboard-Excel-
Interactive Sales Analytics Dashboard built in Microsoft Excel to analyze sales performance and uncover actionable business insights. The project includes data cleaning, KPI analysis, interactive charts, PivotTables, slicers, and dynamic visualizations to track sales, profit, orders, and product performance.

Tools: Microsoft Excel, PivotTables, Pivot Charts, Slicers, Power Query, Excel formulas.
